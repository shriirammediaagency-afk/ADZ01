# Adzinox Private Limited — website starter

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a browser, or run a local static server from this folder:
   `python3 -m http.server 8000`
3. Visit `http://localhost:8000`.

## Deploy
Upload `index.html`, `styles.css`, and `script.js` to the same directory on Hostinger, Netlify, Vercel (static), or any standard web host.

## Before going live
- Replace `hello@adzinox.com`, the WhatsApp number, and all contact details with verified company information.
- Replace Unsplash portfolio/editorial images with approved assets and update alt text.
- Replace illustrative project descriptions and stats with verified case studies. No results are claimed by this starter.
- Connect the enquiry form to Formspree, a CRM, or your own backend. It currently validates locally and does not send or store submissions.
- Connect the Ask Adzinox UI to a real chatbot if required.
- Add your actual social profiles, privacy policy, terms, cookie policy, sitemap.xml and robots.txt.
- Update the canonical domain and Open Graph image in `index.html`.
- Test mobile layouts, keyboard navigation, contrast, forms, and Lighthouse on your deployed domain.

## Notes
This is the requested easy-to-host option A: semantic single-page HTML, CSS and vanilla JS. Google Fonts and GSAP are loaded from CDNs; the hero particle canvas is custom lightweight canvas code, avoiding a large Three.js dependency. Reduced-motion preferences are respected. The portfolio and blog content are clearly illustrative placeholders.
